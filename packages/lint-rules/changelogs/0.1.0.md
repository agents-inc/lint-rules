## Changed

### #24 — `check` runs its own ESLint and oxlint

- `eslint` 10.12.0 and `oxlint` 1.87.0 are dependencies of `@agents-inc/lint-rules`, pinned to the versions
  its rule catalog was generated from (owner 2026-10-11: the runner brings "its own"). They were peer
  dependencies (`^10.0.0` and `^1.86.0`), and `typescript` is now the only peer. `package-manifests.test.ts`
  checks both pins against rule-data's `inventory.json`.
- `check` works with whatever ESLint and oxlint the project installs. `packed-install.integration.test.ts`
  installs the packed tarball and runs `npx agents-inc-lint check`, beside our engine versions and beside
  ESLint 9.34 with oxlint 1.70.
- The editor set still needs ESLint 10: `mergeEslintConfig` refuses an older ESLint that resolves from
  `tsconfigRootDir` (owner 2026-10-14). With no oxlint peer range left, the oxlint merge's refusals advise
  `^1.86.0`, the oldest oxlint both oxlint merge differential suites pass on.

### #73 — the README says the package is ESM only

- An ESLint config that imports the package must be ESM, such as `eslint.config.mjs`. From an
  `eslint.config.cjs`, Node throws `ERR_PACKAGE_PATH_NOT_EXPORTED`, which does not say why. The owner's answer
  was to document it, with no code change (q73). The README's new Install section does.

### q-npm-peer-warnings — the README names npm's two expected warnings

- Beside ESLint 10, `npm install` warns `ERESOLVE overriding peer dependency` for eslint-plugin-react and
  eslint-plugin-react-perf, which do not list ESLint 10 yet. The README says the warnings are expected and the
  install succeeds, and `packed-install.integration.test.ts` pins them.

### Expressive-TypeScript rounds 1–3 — the code reads as named steps, behaviour unchanged

- **lint-rules:**
  - Orchestrators name their steps (`optionsProbeOf`, `blocksOfScopedRules`, `fixEnginesOf`,
    `changedLinesAfterTheFixes`, `eslintEngineOf`).
  - Hand-written group-bys, rule-ID splits and regex group reads go through `groupBy`, `ruleNameOf`,
    `pluginPrefixOf` and `namedGroupOf`.
  - Choices over the package's own unions are exhaustive switches.
  - `SIGNALS`, `EXIT_CODE_OF_SIGNAL` and `UNSCOPED` are `as const satisfies`, so a misspelt signal or a stray
    key is a type error.
- **rule-data:** one reader, `whenSuppressionsParsedBy`, parses each suppression mode's setting, and the
  generator's steps are named. No generated file changed.
- **eslint-plugin-house:**
  - `no-nested-interactive` and `no-focusable-content-in-aria-hidden` decide in pure functions and report from
    one place.
  - `bracedExpressionOf` and `dottedPropertyNameOf` in `shared/` replace six hand-written copies.
  - `housePlugin` satisfies `TSESLint.FlatConfig.Plugin`.
- **Leftovers:** `hasErrorCode`, `messageOf` and `slashSeparated` each have one copy, in `core/`, and module
  constant arrays are typed read-only.
- The packed package gives the same results as before on four engine setups.

## Fixed

### `no-section-banner` — deleting a one-line banner keeps the code either side apart

- The autofix removed a one-line banner between code with nothing in its place, so `typeof/*----*/b` became
  `typeofb`. Measured, it also:
  - made `1 / /*----*//a/` a line comment that dropped the rest of the line;
  - read a word after a regular expression as the expression's flags;
  - turned TypeScript's `a!/*----*/= 1` into `a != 1`.
- It now adds a space where the characters either side would read as one token: two word characters, a
  regular expression's closing `/` and a word, a digit and a dot, or one of `++ -- // != << <! !-`. A character
  outside Unicode's basic plane is read whole.
- **Written limit:** it decides from characters, not tokens, so it can add a space nothing needed: `a1/*----*/.b`
  gives `a1 .b`. A space is always safe to the parser.

## Proposed standards

From `docs/work/learnings.md`; none has landed in `CLAUDE.md`.

- Nothing that can throw runs while a test file is collected (an `it.each` table, a `describe` body).
- A code comment states the reason, not a decision ID.
- A function returning a field plus values derived from it names what it adds.
- When a refactor merges call sites, recheck each helper left with one caller.
- Before calling a Stryker range covered, list its changed lines with no Killed mutant and break each one by
  hand.
- Every test that loads the ESLint entry or spawns an engine CLI calls `allowEveryTestForParallelLoad()`.
- Agent notes quote changed code verbatim, or name only symbols that exist.
- How an exhaustive switch over a union is written is the owner's call (Backlog).
